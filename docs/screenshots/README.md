# Screenshots

Drop the screenshots referenced by the main `README.md` into this folder:

| File | Suggested shot |
| ---- | -------------- |
| `dashboard.png` | The Dashboard in **Demo mode** (hero + stat cards + warnings) |
| `panic-mode.png` | The Panic Mode screen |
| `mobile.png` | The app on a narrow/mobile viewport |

How to capture good ones:

1. `npm run dev`, switch to **Demo mode** (top-right toggle) so no personal data is shown.
2. Take a clean browser screenshot (hide bookmarks bar).
3. For the mobile shot, use your browser dev tools device toolbar (e.g. iPhone 14).
4. Save them here with the exact filenames above and commit.
